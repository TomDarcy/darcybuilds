How it works

From the process to the application

  1. Show me the process

    Start with the spreadsheet, document or workflow holding everything together. We check the fit in a free 30-minute discussion.

  2. I map the workflow

    I visit your factory to see the users, data, rules and exceptions first-hand. We agree the output, acceptance criteria, scope and fixed price.

  3. I build the first working version

    Your team responds to working software using the real workflow, so we can resolve the details together.

  4. We refine and deploy

    Refine within the agreed scope, check acceptance criteria, and hand over with documentation and clear ownership.

Ownership & handover

Your application isn’t held hostage.

You own your data. You can access it and export it in a usable format. You don’t need an ongoing retainer to keep using what we’ve built.

Before work starts, we agree the source code ownership and access, where the application will run, who controls the hosting accounts and what documentation you’ll receive. Any ongoing costs and third-party licences are made clear up front.

The handover covers how the application works, how it’s deployed and what keeps it running. Another competent developer can take over its maintenance or development, with the code, access and documentation they need.
