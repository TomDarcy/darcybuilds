# Case-study evidence

FactoryPulse images are genuine, unmodified product screenshots from the existing FactoryPulse documentation:

- `factorypulse-overview.png`: product home (`images/dashboard.png`).
- `factorypulse-boards.png`: board designer (`images/boards/designer.png`).
- `factorypulse-improvement.png`: improvement project board (`images/ci/dashboard.png`).
- `factorypulse-problems.png`: problem-solving workflow (`images/problems/edit.png`).

The project target visible in the improvement board is not a measured customer result.

The ERP and inspection images are representative reconstructions created for the website, not original client screenshots. All work orders, suppliers, part numbers, dates, measurements and quantities are fictional. Each image carries its own reconstruction label, as do the captions on the website.

Editable source interfaces are in `reconstructions/`. Render them in a browser at 1280px viewport width, with device scale 1, and capture the full page to regenerate their corresponding PNG files. They are static visual artefacts, not functional product demos.

The inspection chart uses a fictional measurement sequence and illustrative control limits. Product specification limits are displayed separately. Do not present these values as measured project results or a process-capability study.
